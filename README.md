# Когортный анализ благотворителей фонда «АиФ. Доброе сердце»

Аналитический проект: SQL-исследование поведения благотворителей
фонда «АиФ. Доброе сердце» — MAU, Retention Rate, средний чек и LTV.

> Учебный кейс (спринт 9, курс по аналитике данных). Данные предоставлены фондом.

---

## Задача

Фонд помогает подопечным с оплатой операций, лекарств и оборудования. Чтобы
эффективнее работать с благотворителями, фонду нужно понимать:

1. Как меняется число активных благотворителей по месяцам (**MAU**)?
2. Как удерживаются благотворители после крупной кампании августа 2022 — и есть ли разница между мужчинами и женщинами (**Retention Rate**)?
3. Кто жертвует чаще и крупнее (**средний чек** по полу)?
4. Сколько в среднем приносит благотворитель из Москвы, Санкт-Петербурга и Екатеринбурга (**LTV**)?

## Данные

PostgreSQL (Yandex Cloud), схема `aif_data`:

| Таблица | Содержание | Ключевые поля |
|---|---|---|
| `id_donor` | профили благотворителей | `CustomerIdsMindboxId`, `CustomerSex`, `CustomerAreaName`, подписки по каналам |
| `order` | пожертвования (= заказы), 2021 — 03.2024 | `OrderCustomerIdsMindboxId`, `OrderFirstActionDateTimeUtc`, `OrderTotalPrice`, `OrderLineStatusIdsExternalId` |
| `channel` | логи действий, 03.2022 — 03.2024 | `User_id`, `User_action`, `Action_date`, UTM-метки |

Имена полей в CamelCase — в запросах они берутся в двойные кавычки.

## Методология

- **Активный пользователь** — благотворитель хотя бы с одним *оплаченным* (`Paid`) пожертвованием в месяце.
- **Когорта.** Поле `CustomerChangeDateTimeUtc` перезаписывается при каждом редактировании профиля, поэтому реальная дата регистрации недоступна. Когорта строится иначе: все, кто оплатил пожертвование в **августе 2022** (месяц крупной медийной кампании), независимо от того, новые они или нет. Благотворители без указанного пола исключены.
- **Retention Rate** месяца *N* = доля когорты, оплатившая пожертвование через *N* календарных месяцев после августа 2022.
- **Средний чек** = средняя сумма оплаченного заказа.
- **LTV** = суммарные оплаченные пожертвования / число уникальных благотворителей за весь период.

### Что улучшено относительно эталонного решения

| Проблема | Решение |
|---|---|
| `BETWEEN '2022-08-01' AND '2022-08-31'` теряет платежи 31 августа после 00:00 | полуинтервал по месяцу (`activity_month = '2022-08-01'`) |
| Месяц жизни через `дни / 30` смещается на длинном горизонте | календарная разница месяцев |
| `OrderTotalPrice` — сумма всего заказа, при нескольких позициях задваивается в `SUM` | данные сначала сворачиваются до уровня заказа |
| Знаменатель retention через `MAX() OVER (...)` | явный `FIRST_VALUE` — размер когорты в месяце 0 |

## Структура репозитория

```
aif-donors-cohort-analysis/
├── sql/
│   ├── 01_mau.sql                  # динамика MAU
│   ├── 02_retention_by_sex.sql     # retention когорты 08.2022 по полу
│   ├── 03_avg_check_by_sex.sql     # число заказов и средний чек по полу
│   └── 04_ltv_by_city.sql          # LTV по трём городам
├── src/
│   └── run_analysis.py             # запускает запросы, строит графики и сводку
├── reports/
│   ├── figures/                    # графики (PNG)
│   └── summary.md                  # сводка с цифрами (генерируется)
```

## Как запустить

```bash
git clone https://github.com/EfimovAN18/aif-donors-cohort-analysis.git
cd aif-donors-cohort-analysis
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                                 # впишите пароль к БД
python src/run_analysis.py
```

Скрипт сохранит CSV в `data/results/`, графики в `reports/figures/` и сводку в `reports/summary.md`.

## Выводы

**MAU.** Число активных благотворителей в целом растёт, но с заметными пиками и спадами. Самый выраженный всплеск — август 2022, совпадающий с медийной кампанией фонда; колебания в остальные месяцы похожи на сезонность и эффект отдельных акций и сборов.

**Retention Rate.** Удержание резко падает уже после первого месяца — значительная часть привлечённых кампанией жертвует однократно. Женская когорта удерживается лучше мужской на всём горизонте.

**Средний чек.** Женщины оформляют больше пожертвований, но средний чек у них ниже. Мужчины жертвуют реже, но крупнее.

**LTV по городам.** Больше всего благотворителей из Москвы, а наибольший LTV — в Екатеринбурге при небольшом числе доноров (выборка мала, вывод стоит перепроверять на новых данных).

### Рекомендации фонду

- После крупных кампаний запускать онбординг-цепочку и предлагать подписку на регулярный платёж — основная потеря аудитории происходит в первый месяц.
- Для мужской аудитории делать акцент на адресных сборах на крупные цели (операции, оборудование); для женской — на регулярных небольших пожертвованиях и подписке.
- Заполнять пол и город в профиле (например, при оформлении платежа) — сейчас значительная часть доноров выпадает из анализа.
